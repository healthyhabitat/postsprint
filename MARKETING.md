## Reply templates

**“How is this different from ChatGPT?”**  
Productized flow, stable 7-day structure, unlockable Markdown pack, and copy that references *your* changelog — not a chat transcript of marketing tips.

**“Can I use this for a big company release?”**  
Yes — paste the release notes, set audience + tone (calm/technical work well). Output is still ready-to-post, not a strategy deck.

**“Do you train on my changelogs?”**  
No model training pipeline. Generation runs on a deterministic template engine (optional OpenAI polish only if configured). We don’t sell your prompts.
